Atalhos da área de trabalho não funcionam

O problema

Ao dar dois cliques em um atalho da área de trabalho, nada acontece, aparece a mensagem "O item ao qual este atalho se refere foi alterado ou movido", o sistema pergunta com qual programa abrir o arquivo ou o ícone fica em branco.

Possíveis causas

O programa foi movido, desinstalado ou atualizado para outra pasta, e o atalho continua apontando para o caminho antigo. Também pode ser a associação dos arquivos de atalho (.lnk no Windows, .desktop no Linux) corrompida, o cache de ícones (a cópia das imagens dos ícones que o sistema guarda para carregar mais rápido) danificado ou um antivírus bloqueando o programa.

Solução no Windows

Clique com o botão direito no atalho, escolha Propriedades e confira o campo Destino. Clique em Abrir local do arquivo: se o Windows avisar que o item não existe mais, o programa foi movido ou desinstalado. Apague o atalho e, se o programa ainda estiver instalado, crie um novo pelo menu Iniciar: botão direito no programa > Abrir local do arquivo > botão direito > Enviar para > Área de trabalho (criar atalho).

Se todos os atalhos abrirem com o mesmo programa, como o Bloco de Notas, a associação dos arquivos .lnk foi corrompida. Abra o Prompt de Comando como administrador e execute sfc /scannow (System File Checker, que verifica e repara os arquivos do sistema) e depois DISM /Online /Cleanup-Image /RestoreHealth (que repara a imagem do Windows usada pelo sfc), reiniciando ao final.

Se os ícones estiverem em branco, reinicie o Windows Explorer pelo Gerenciador de Tarefas ou execute ie4uinit.exe -show no Executar (Win + R) para recriar o cache de ícones.

Solução no Linux

No Linux, os atalhos são arquivos .desktop, que ficam em ~/.local/share/applications e /usr/share/applications. Abra o atalho em um editor de texto e confira a linha Exec=, que indica o comando executado: se o programa mudou de lugar, corrija o caminho.

No Ubuntu, atalhos copiados para a área de trabalho precisam ser liberados: clique com o botão direito neles e escolha Permitir execução. Se o ícone estiver em branco, apague o cache com rm -rf ~/.cache/thumbnails e reinicie a sessão. Se o programa foi desinstalado, reinstale-o pela loja de aplicativos ou com sudo apt install nome-do-programa.
