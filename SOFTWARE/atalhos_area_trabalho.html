Atalhos de aplicativos na área de trabalho não funcionam

Este problema acontece quando, ao dar dois cliques em um atalho da área de trabalho, nada acontece, aparece a mensagem "O item ao qual este atalho se refere foi alterado ou movido", o Windows pergunta com qual programa abrir o arquivo ou o ícone fica em branco. As causas mais comuns são o programa ter sido movido, atualizado para outra pasta ou desinstalado, a associação dos arquivos de atalho (.lnk) corrompida, o cache de ícones danificado ou um antivírus bloqueando o programa.

Solução

O primeiro passo é verificar para onde o atalho aponta. Clique com o botão direito no atalho, escolha Propriedades e confira o campo Destino. Clique em Abrir local do arquivo: se o Windows avisar que o item não existe mais, o programa foi movido ou desinstalado. Nesse caso, apague o atalho e, se o programa ainda estiver instalado, crie um novo: procure o programa no menu Iniciar, clique com o botão direito e escolha Abrir local do arquivo, depois clique com o botão direito no programa e selecione Mostrar mais opções > Enviar para > Área de trabalho (criar atalho). Se o programa não aparecer no menu Iniciar, reinstale-o.

Se o atalho aponta para o lugar certo, mas o programa não abre, tente executá-lo direto pela pasta de instalação ou clicando com o botão direito e escolhendo Executar como administrador. Verifique também o histórico de proteção da Segurança do Windows (ou do seu antivírus), pois o programa pode ter sido colocado em quarentena. Se mesmo assim não abrir, o problema é no próprio aplicativo, e a solução é desinstalá-lo e instalá-lo novamente.

Se todos os atalhos pararem de funcionar ao mesmo tempo ou passarem a abrir com o mesmo programa (como o Bloco de Notas), a associação dos arquivos .lnk foi corrompida, geralmente por vírus ou por uma escolha errada em "Abrir com". Abra o Prompt de Comando como administrador e execute sfc /scannow e, em seguida, DISM /Online /Cleanup-Image /RestoreHealth, reiniciando o computador ao final. Faça também uma verificação completa com a Segurança do Windows. Se o problema começou há pouco tempo, a Restauração do Sistema para uma data anterior também resolve.

Se os atalhos funcionam, mas os ícones aparecem em branco ou errados, o problema é o cache de ícones. Abra o Gerenciador de Tarefas (Ctrl + Shift + Esc), clique com o botão direito no Windows Explorer e escolha Reiniciar. Se não resolver, pressione Win + R, digite ie4uinit.exe -show e pressione Enter para recriar o cache de ícones. Se o problema for com atalhos do teclado, veja a página Atalhos do teclado não funcionam.
