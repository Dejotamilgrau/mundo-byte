Atalhos do teclado não funcionam

O problema

Combinações de teclas, como Ctrl + C, Ctrl + V, Alt + Tab ou as combinações com a tecla Windows (chamada de tecla Super no Linux), param de responder, mesmo que as letras continuem sendo digitadas normalmente.

Possíveis causas

Recursos de acessibilidade ativados sem querer (Teclas de Aderência e Teclas de Filtragem), a tecla Windows bloqueada pelo Modo Jogo em teclados gamer, programas em segundo plano que capturam as combinações de teclas, o processo da interface gráfica travado (Windows Explorer no Windows, GNOME Shell no Ubuntu) ou o driver do teclado corrompido.

Solução no Windows

Muitos teclados gamer e notebooks têm uma combinação (como Fn + F6, Fn + Windows ou um botão com cadeado) que bloqueia a tecla Windows. Pressione-a novamente para desbloquear e confira se a tecla Fn Lock não está invertendo as funções das teclas F1 a F12.

Desative os recursos de acessibilidade em Configurações > Acessibilidade > Teclado (Teclas de Aderência, Teclas de Filtragem e Teclas de Alternância). Eles costumam ser ligados sem querer ao pressionar Shift cinco vezes ou segurar o Shift direito por oito segundos.

Se o Alt + Tab ou os atalhos com a tecla Windows pararem de repente, reinicie o Windows Explorer pelo Gerenciador de Tarefas (Ctrl + Shift + Esc) e feche gravadores de tela, sobreposições de jogos (overlays) e softwares de macro. Se continuar, desinstale o teclado no Gerenciador de Dispositivos e reinicie para o driver ser reinstalado.

Solução no Linux

No Ubuntu, confira em Configurações > Acessibilidade > Digitação se as Teclas de Aderência e as Teclas Lentas estão desligadas. Os atalhos ficam em Configurações > Teclado > Ver e personalizar atalhos, onde também existe a opção Restaurar tudo, que volta aos atalhos originais.

Se os atalhos pararem depois de alguma personalização, o comando gsettings reset-recursively org.gnome.desktop.wm.keybindings restaura os atalhos de janelas. Para testar se o sistema está recebendo as teclas, o programa xev (no Xorg) ou sudo showkey (no terminal de texto) mostra o código de cada tecla pressionada.
