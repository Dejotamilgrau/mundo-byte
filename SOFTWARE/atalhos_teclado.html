Atalhos do teclado não funcionam

Este problema acontece quando atalhos de teclado, como Ctrl + C, Ctrl + V, Alt + Tab ou as combinações com a tecla Windows (Win + E, Win + D, Win + R), param de responder, mesmo que as letras continuem sendo digitadas normalmente. As causas mais comuns são recursos de acessibilidade ativados sem querer (Teclas de Aderência e Teclas de Filtragem), a tecla Windows bloqueada em teclados gamer, programas em segundo plano que "capturam" as combinações de teclas, o Windows Explorer travado e o driver do teclado corrompido.

Solução

Comece verificando o próprio teclado. Muitos teclados gamer e notebooks têm uma tecla ou combinação (como Fn + F6, Fn + Windows ou um botão com cadeado) que bloqueia a tecla Windows, ativando o chamado Modo Jogo. Pressione essa combinação novamente para desbloquear. Em notebooks, confira também se a tecla Fn Lock não está invertendo as funções das teclas F1 a F12. Se possível, teste outro teclado para descartar defeito físico.

Em seguida, desative os recursos de acessibilidade em Configurações > Acessibilidade > Teclado, desligando as opções Teclas de Aderência, Teclas de Filtragem e Teclas de Alternância, além dos atalhos que as ativam. Esses recursos costumam ser ligados sem querer ao pressionar Shift cinco vezes ou segurar o Shift direito por oito segundos, e fazem o teclado se comportar de forma estranha.

Se os atalhos com a tecla Windows ou o Alt + Tab pararem de funcionar de repente, reinicie o Windows Explorer. Abra o Gerenciador de Tarefas (Ctrl + Shift + Esc), encontre o Windows Explorer na lista, clique com o botão direito e escolha Reiniciar. Aproveite para finalizar programas que podem estar capturando os atalhos, como gravadores de tela, overlays de jogos e softwares de macro do teclado.

Se o problema continuar, abra o Gerenciador de Dispositivos, expanda Teclados, clique com o botão direito no teclado, escolha Desinstalar dispositivo e reinicie o computador para o driver ser reinstalado. Veja também a página Drivers desatualizados ou corrompidos. Por fim, abra o Prompt de Comando como administrador e execute sfc /scannow para corrigir arquivos do sistema corrompidos.
