Espaço em disco ficando cheio sozinho

O problema

O armazenamento do sistema (a unidade C: no Windows, ou a partição raiz "/" no Linux) vai perdendo espaço livre sem que o usuário tenha salvo arquivos novos, até o computador ficar lento e mostrar avisos de espaço insuficiente.

Possíveis causas

O sistema e os aplicativos geram arquivos temporários continuamente. Também ocupam espaço os pontos de restauração (cópias do estado do sistema para desfazer alterações), o arquivo de paginação (espaço do disco usado como extensão da memória RAM), o arquivo de hibernação, as atualizações antigas e, no Linux, os pacotes baixados pelo gerenciador de pacotes e os registros (logs) do sistema.

Solução no Windows

Pressione Win + R, digite cleanmgr e selecione a unidade C:. Clique em Limpar arquivos do sistema e marque arquivos do Windows Update, arquivos temporários e a Lixeira. Depois, abra o Executar, digite %temp% e apague o conteúdo da pasta, ignorando os itens em uso.

Para evitar que o problema volte, ative o Sensor de Armazenamento em Configurações > Sistema > Armazenamento, que exclui arquivos desnecessários automaticamente.

Solução no Linux

O comando df -h mostra o espaço livre em cada partição, e o Analisador de uso de disco (baobab) mostra graficamente quais pastas ocupam mais espaço.

Para liberar espaço, execute sudo apt clean (apaga os pacotes já baixados), sudo apt autoremove (remove dependências e kernels antigos que não são mais usados) e sudo journalctl --vacuum-size=200M (reduz os registros do sistema a 200 MB). Esvazie também a Lixeira e a pasta ~/.cache.
