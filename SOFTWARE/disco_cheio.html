Espaço em disco ficando cheio sozinho no Windows

Este problema normalmente ocorre porque o Windows e diversos aplicativos geram e acumulam arquivos temporários continuamente em segundo plano. Entre os principais vilões desse consumo estão os arquivos temporários de instalações e navegação, os pontos de restauração automática do sistema e os arquivos de paginação e hibernação utilizados pela memória RAM.

Solução

Para resolver esse problema é possivel utilizar a ferramenta nativa Limpeza de Disco pressionando Win + R, digitando cleanmgr e selecionando a unidade C:. Ao clicar em Limpar arquivos do sistema, selecione e apague arquivos de atualizações antigas do Windows Update, pontos de restauração e itens da Lixeira.

Além do utilitário, também é recomendado limpar as pastas de armazenamento temporário manualmente. Para isso, abra o menu Executar (Win + R), digite %temp% e apague todo o conteúdo da pasta, ignorando apenas os itens que o sistema informar estarem em uso no momento. Repita o mesmo procedimento digitando temp no Executar.

Para evitar que o problema volte a acontecer, é possivel ativar o Sensor de Armazenamento em Configurações > Sistema > Armazenamento, permitindo que o Windows faça essa eliminação de arquivos desnecessários de forma automática. Ao final, abra o "Este Computador" para verificar se a barra da unidade C: voltou a indicar um aumento significativo de espaço livre.
