Erro de biblioteca ausente (DLL) ao iniciar um programa

O problema

Ao abrir um jogo ou programa, aparece uma mensagem dizendo que ele não pode ser iniciado porque falta um arquivo, como MSVCP140.dll ou VCRUNTIME140.dll. Esses arquivos são bibliotecas compartilhadas (conjuntos de funções prontas que vários programas usam). No Windows elas têm a extensão .dll; no Linux, .so, e o erro aparece como "error while loading shared libraries".

Possíveis causas

O pacote que contém a biblioteca não está instalado, está corrompido ou falta a versão da arquitetura certa (32 ou 64 bits). No Windows, a maioria dessas DLLs faz parte do Microsoft Visual C++ Redistributable ou do DirectX. No Linux, a biblioteca pertence a um pacote que não foi instalado como dependência.

Solução no Windows

Baixe o Microsoft Visual C++ Redistributable mais recente no site oficial da Microsoft e instale as duas versões, x64 e x86, porque muitos jogos são de 32 bits mesmo em um Windows de 64 bits. Se ele já estiver instalado, repare-o em Configurações > Aplicativos > Aplicativos instalados > Modificar > Reparar.

Se o arquivo for parecido com d3dx9_43.dll ou xinput1_3.dll, instale o Runtime do DirectX para usuário final. Na Steam, use Propriedades > Arquivos instalados > Verificar integridade dos arquivos. Nunca baixe arquivos .dll avulsos de sites de DLL: eles podem conter malware ou ser da versão errada.

Solução no Linux

O comando ldd /caminho/do/programa lista as bibliotecas de que o programa precisa e marca como "not found" as que estão faltando. Para descobrir qual pacote contém a biblioteca, instale o apt-file (sudo apt install apt-file e sudo apt-file update) e execute apt-file search nome-da-biblioteca.so.

Depois, instale o pacote encontrado com sudo apt install nome-do-pacote. Se o programa veio da loja de aplicativos em formato Flatpak ou Snap, as bibliotecas já vêm junto: reinstalar o programa costuma resolver.
