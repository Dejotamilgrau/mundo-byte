Erro de DLL ausente ao iniciar um programa

Ao abrir um jogo ou programa, aparece uma mensagem dizendo que ele não pode ser iniciado porque falta um arquivo, como MSVCP140.dll, VCRUNTIME140.dll ou VCRUNTIME140_1.dll. Esses arquivos fazem parte do Microsoft Visual C++ Redistributable, um pacote que muitos programas precisam para funcionar. O erro aparece quando o pacote não está instalado, está corrompido ou está faltando a versão de 32 ou de 64 bits.

Solução

Baixe o Microsoft Visual C++ Redistributable mais recente pelo site oficial da Microsoft e instale as duas versões, x64 e x86, porque muitos jogos são de 32 bits mesmo em um Windows de 64 bits. Se ele já estiver instalado, repare: em Configurações > Aplicativos > Aplicativos instalados, clique no Microsoft Visual C++ 2015-2022 Redistributable, escolha Modificar e depois Reparar. Reinicie o computador e tente abrir o programa de novo.

Se o arquivo da mensagem for parecido com d3dx9_43.dll ou xinput1_3.dll, o que falta é o DirectX antigo: instale o Runtime do DirectX para usuário final, também pelo site da Microsoft. Em jogos da Steam, clique com o botão direito no jogo, vá em Propriedades > Arquivos instalados > Verificar integridade dos arquivos, que baixa de novo o que estiver faltando.

Nunca baixe arquivos .dll avulsos de sites de DLL: eles podem ter vírus ou ser da versão errada. Se o erro continuar, reinstale o programa e execute sfc /scannow no Prompt de Comando como administrador. Se o programa trava ou fecha sem mostrar erro de DLL, veja a página Programa não abre ou fecha sozinho.
