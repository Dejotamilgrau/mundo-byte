Loop de reparo automático

Este problema ocorre quando o Windows tenta corrigir erros de inicialização de forma autônoma, falha e entra num ciclo infinito de reinicializações.

Solução

Para resolver esse problema, é necessário acessar o menu de Opções Avançadas. Caso a tela azul de reparo não apareça automaticamente, você pode forçar o acesso ligando o computador e, assim que o logotipo do fabricante surgir, mantendo o botão Power pressionado por 10 segundos para desligá-lo. Após repetir esse processo de duas a três vezes, o sistema carregará a tela de preparação do reparo. Nela, navegue em Opções Avançadas > Solução de problemas > Opções Avançadas.

A primeira tentativa de solução deve ser a opção Reparo de Inicialização, em que o próprio sistema tenta identificar e corrigir os arquivos corrompidos. Se o Windows exibir a mensagem de que não pôde reparar o computador, o próximo passo é tentar a Restauração do Sistema, que não faz você perder arquivos pessoais. Ao selecionar essa opção, escolha sua conta de usuário, insira a senha e selecione um ponto de restauração criado antes do surgimento do problema para voltar o sistema a um estado funcional.

Caso os recursos automáticos falhem, é preciso reconstruir a estrutura de inicialização do disco manualmente utilizando o Prompt de Comando, localizado no mesmo menu de opções avançadas. Com o terminal aberto, execute a sequência de comandos digitando bootrec /fixmbr, bootrec /fixboot (caso ocorra erro de acesso negado, digite bootsect /nt60 sys antes de tentar novamente), bootrec /scanos e bootrec /rebuildbcd, pressionando Enter após cada um. Finalize digitando exit e clique em continuar para o Windows.

Se o registro do sistema estiver criticamente danificado e nenhuma das alternativas anteriores funcionar, o último recurso local é a restauração do sistema mantendo os dados. Em Solução de problemas, selecione Restaurar o PC e escolha a opção Manter meus arquivos. O Windows será reinstalado preservando seus documentos e dados pessoais, embora os programas precisem ser instalados novamente após a conclusão.
