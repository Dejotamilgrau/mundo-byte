Problemas de software

Problemas de software que encontramos durante a montagem e manutenção dos computadores, com as causas e como resolvemos cada um.

Windows ou Linux?

Os dois são sistemas operacionais: o programa principal do computador, que controla o hardware (as peças físicas) e permite que os outros programas funcionem. Por isso, cada problema desta página traz a solução nos dois sistemas.

Windows

Sistema da Microsoft, pago (com licença) e de código fechado. É o mais usado em computadores pessoais. As configurações ficam no aplicativo Configurações e no Painel de Controle, e os comandos são digitados no Prompt de Comando ou no PowerShell.

Linux

Sistema livre, gratuito e de código aberto, distribuído em versões chamadas distribuições, como o Ubuntu, usado no laboratório. Os programas são instalados por um gerenciador de pacotes (como o apt) e muitos ajustes são feitos no terminal, quase sempre com sudo para ter permissão de administrador.
