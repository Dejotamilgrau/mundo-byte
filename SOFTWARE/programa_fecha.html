Programa não abre ou fecha sozinho

O problema

Um aplicativo congela e mostra a mensagem "Não está respondendo", ou fecha logo depois de ser aberto, sem aviso. No Linux, o sistema mostra "O aplicativo não está respondendo" com as opções Esperar e Forçar saída.

Possíveis causas

Arquivos do programa corrompidos, falta de bibliotecas ou componentes de que ele depende, falta de memória RAM, incompatibilidade com a versão do sistema operacional ou bloqueio do antivírus.

Solução no Windows

Quando o programa congelar, abra o Gerenciador de Tarefas (Ctrl + Shift + Esc), selecione-o e clique em Finalizar tarefa. Instale as atualizações pendentes do Windows e do programa. Se ele fecha ao abrir, tente Executar como administrador ou reinstale-o a partir do site oficial.

Para programas antigos, clique com o botão direito no atalho, vá em Propriedades > Compatibilidade e marque Executar este programa em modo de compatibilidade. Para descobrir a causa de um fechamento, abra o Visualizador de Eventos (eventvwr.msc) > Logs do Windows > Aplicativo e procure erros com o nome do programa.

Solução no Linux

Para encerrar um programa travado, use o Monitor do Sistema ou o terminal: pkill nome-do-programa ou xkill (que transforma o cursor em um "X" para clicar na janela travada). Abrir o programa pelo terminal, digitando o nome dele, mostra as mensagens de erro que explicam por que ele fechou.

Se o problema for falta de memória, o comando free -h mostra a RAM livre. Para corrigir arquivos do programa, reinstale-o com sudo apt install --reinstall nome-do-pacote. Se aparecer erro de biblioteca, veja a página Erro de biblioteca ausente (DLL).
