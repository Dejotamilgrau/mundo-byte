Tela preta após o login

O computador liga, mostra a tela de boas-vindas, mas depois a área de trabalho fica totalmente preta, só com o cursor do mouse. Quase sempre o culpado é o Windows Explorer (explorer.exe), o processo que desenha a área de trabalho, a barra de tarefas e o menu Iniciar: ele não abriu ou travou. Isso pode vir de uma atualização mal instalada, de arquivos do sistema corrompidos, do driver de vídeo ou de um vírus.

Solução

Mesmo com a tela preta, o Gerenciador de Tarefas funciona. Aperte Ctrl + Shift + Esc, vá em Arquivo > Executar nova tarefa, digite explorer.exe e clique em OK. Se a área de trabalho aparecer, o problema era só o Explorer que não abriu. Reinicie o computador para ver se volta a acontecer.

Se a tela continuar preta, o problema pode ser o vídeo. Aperte Win + Ctrl + Shift + B para reiniciar o driver de vídeo e Win + P para conferir se a imagem não está indo para um segundo monitor desligado. Se começou depois de instalar um driver novo, abra o Gerenciador de Dispositivos, expanda Adaptadores de vídeo, entre em Propriedades > Driver e clique em Reverter driver.

Se o problema se repete toda vez, verifique os arquivos do sistema. No Gerenciador de Tarefas, em Executar nova tarefa, digite cmd, marque Criar esta tarefa com privilégios administrativos e execute sfc /scannow e depois DISM /Online /Cleanup-Image /RestoreHealth. Se tudo começou depois de uma atualização, desinstale-a em Configurações > Windows Update > Histórico de atualizações > Desinstalar atualizações. Também vale passar o antivírus, porque alguns vírus impedem o Explorer de abrir. Se nada resolver, veja a página Sistema operacional corrompido.
