Tela preta após o login

O problema

O computador liga, mostra a tela de login, mas depois a área de trabalho fica totalmente preta, às vezes só com o cursor do mouse.

Possíveis causas

No Windows, quase sempre o Windows Explorer (explorer.exe), o processo que exibe a área de trabalho, a barra de tarefas e o menu Iniciar, não abriu ou travou. No Linux, a causa mais comum é o servidor gráfico (Xorg ou Wayland, o programa que desenha as janelas) não conseguir iniciar, geralmente por problema no driver de vídeo. Atualizações mal instaladas, arquivos corrompidos e malware também podem causar o problema.

Solução no Windows

Mesmo com a tela preta, o Gerenciador de Tarefas funciona. Aperte Ctrl + Shift + Esc, vá em Arquivo > Executar nova tarefa, digite explorer.exe e clique em OK. Se a área de trabalho aparecer, o problema era o Explorer.

Se continuar preta, aperte Win + Ctrl + Shift + B para reiniciar o driver de vídeo e Win + P para conferir se a imagem não está indo para um segundo monitor. Se começou depois de um driver novo, use Reverter driver em Adaptadores de vídeo, no Gerenciador de Dispositivos. Para verificar o sistema, em Executar nova tarefa digite cmd, marque Criar esta tarefa com privilégios administrativos e execute sfc /scannow e DISM /Online /Cleanup-Image /RestoreHealth.

Solução no Linux

Aperte Ctrl + Alt + F3 para abrir um terminal de texto e faça login. O comando journalctl -b -p err mostra os erros da inicialização atual. Se o problema começou depois de instalar o driver da NVIDIA, remova-o com sudo apt purge 'nvidia-*' e reinicie para voltar ao driver livre (nouveau).

Na tela de login, a engrenagem no canto permite escolher entre Ubuntu (Wayland) e Ubuntu no Xorg: trocar de um para o outro resolve muitos casos. Também é possível reiniciar o gerenciador de login com sudo systemctl restart gdm3.
